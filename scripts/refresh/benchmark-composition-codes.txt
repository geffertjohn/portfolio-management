# Composition metrics for the category_benchmarks sheet.
#
# Fed to add-sheet-columns.ps1 with -SheetName category_benchmarks -HeaderRow 3
# -FirstDataRow 4 — that sheet's header is row 3, not row 2 like Securities.
#
# THE CODES MATCH securities2 EXACTLY, which is the point: a benchmark measured
# on a different metric than the fund is not a comparison.
#
# NOT the spellings this sheet carried before. Eleven sector columns were
# dropped here in Sep 2026 under names like `technology_exposure`, and the
# YCharts add-in catalogue has no such code — it publishes exactly one form per
# sector and which one varies (`technology_exposure_generic` but
# `energy_exposure`). Re-adding the old spellings would rebuild a set of
# columns that can only ever return nothing.
#
# Fund-only fields are deliberately absent: an index has no expense ratio,
# turnover, holdings count, flows or scorecard.
